Security setup required.
Do not use this page for administration until Cloudflare Access is protecting this route. A hidden link or browser-side password is not secure authentication.

Before enabling owner controls

  1. Create a Cloudflare Access application for this exact admin route.
  2. Allow only your verified owner email address.
  3. Connect a Cloudflare Worker API with server-side authentication.
  4. Store API secrets as environment secrets, never in HTML or GitHub.
  5. Only then connect monitoring and administrative actions.
